Refleksi

Setelah mempelajari Git, saya merasa proses pengelolaan file menjadi lebih teratur dibandingkan cara lama yang menggunakan banyak salinan file dengan nama seperti final, final_revisi, atau final_fix. Dengan Git, setiap perubahan dapat dicatat dalam bentuk commit sehingga riwayat pekerjaan lebih mudah ditelusuri.

Bagian yang menurut saya paling mudah adalah membuat file dan melakukan commit karena langkah-langkahnya cukup jelas. Sementara bagian yang paling menantang adalah memahami hubungan antara repository lokal dan repository di GitHub, terutama saat melakukan push pertama kali.

Menurut saya, keuntungan terbesar Git adalah kemampuannya menyimpan riwayat perubahan secara sistematis tanpa harus membuat banyak salinan file. Selain itu, Git juga sangat membantu ketika bekerja dalam tim karena setiap anggota dapat melihat perubahan yang dilakukan.

Hal yang ingin saya pelajari lebih lanjut adalah penggunaan branch dan merge untuk mendukung kolaborasi yang lebih kompleks.
